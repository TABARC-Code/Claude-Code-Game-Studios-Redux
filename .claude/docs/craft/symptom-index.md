# Symptom index

Read by `/design-craft` (Phase 2) and any craft skill asked a question in the player's own words.

Complaints arrive as symptoms, not causes. Find the closest line, run the skill and phase it names, and
treat the "likely cause" column as a hypothesis to check, not a diagnosis.

| Symptom (as players say it) | Likely cause to check | Skill and phase |
|---|---|---|
| "Whoever goes first wins" | first strike, unanswerable opening, activation advantage | `/exploit-hunt` R1, `/activation-design` Phase 4, `/tempo-curve` opening check |
| "It was over by turn two, then we played it out" | front-loaded lethality, snowball, no comeback | `/tempo-curve`, `/exploit-hunt` R2 |
| "It just grinds" | linear attrition, no tipping point | `/tempo-curve` tipping point |
| "The middle drags" | identical turns, no escalation | `/tempo-curve` session arc |
| "Nobody attacks" or "we both sat still" | disengagement trap, defender wins by default | `/scenario-forge` disengagement traps |
| "Everyone runs to the corners at the end" | preset end with no live objective | `/scenario-forge` end triggers |
| "The dice decided it" | output randomness too heavy, spikes, pivotal luck | `/decision-audit` Phase 3, `/resolution-tuning` Phase 4 |
| "I don't know why I lost" | broken feedback loop, long gap from choice to result | `/decision-audit` Phase 4 |
| "There is only one way to win" | dominant line, multiple goals collapsing to one | `/exploit-hunt` R3, `/core-check` seam checks |
| "My choices don't matter" | solutions or guesses, not decisions | `/decision-audit` Phase 2 |
| "It feels like two games stuck together" | split core | `/core-check` |
| "Too many rules" | orphan rules, incidental complexity | `/core-check` reduce mode, `/model-scope` checks |
| "We argued about the rules" | ambiguity, synonyms, unstated timing | `/rules-draft` check, `/term-register` check |
| "We couldn't find the rule" | book structure, navigation | `/rulebook-architecture` |
| "These two abilities together are broken" | keyword interaction | `/keyword-audit` |
| "Everyone takes the same card" or "nobody plays that one" | mandatory or dead piece, mispricing | `/card-forge`, `/unit-costing` checks |
| "The factions feel the same" | surface asymmetry | `/faction-forge` |
| "The new set made the old one obsolete" | power creep | `/expansion-plan` anti-creep |
| "The meta is solved" | live dominant strategy | `/meta-intervention` |
| "I was just waiting" | downtime, no decisions when inactive | `/activation-design` Phase 4, `/exploit-hunt` R4 |
| "Someone who couldn't win decided who did" | kingmaking | `/table-feel` social outcome |
| "It was mean" or "it felt solitaire" | interaction density off target | `/table-feel` |
| "It works but it's flat" | missing pleasure sources | `/table-feel` pleasure map |
| "Nothing interesting happened" | no emergent chains, no dramatic focus | `/story-engine` |
| "The story said one thing, the points another" | fiction and scoring dissonance | `/story-engine`, `/scenario-forge` |
| "We got stuck and couldn't find the clue" | single-route revelation, stalling failure | `/adventure-forge` information |
| "The world just waited for us" | no fronts or clocks | `/adventure-forge`, `/world-seed` |
| "Losing the first campaign game ruined the rest" | campaign runaway | `/adventure-forge` campaign mode |
| "It doesn't feel like the setting" | theme with no verb home, false affordance | `/core-check`, `/world-seed` |
| "It's a reskin of something else" | no new decision shape | `/mechanic-forge`, `/core-check` remaining value |
| "Setup takes forever" | component load | `/model-scope`, `/core-check` reduce mode |

If a symptom matches nothing here, start at `/core-check` and add a line to this table afterwards.
