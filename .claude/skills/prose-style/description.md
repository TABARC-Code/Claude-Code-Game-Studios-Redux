# prose-style: description

A Claude Code skill that records a game project's writing style once (English variant, dash policy and limit, serial comma, quotes, numbers, capitalised terms) in `design/narrative/style-guide.md`, then checks text against it. Every setting is the user's choice; a blank one is reported as not assessed, never defaulted. Dash counts are measured by a script, not estimated.
