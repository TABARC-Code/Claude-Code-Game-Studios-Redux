# one-page-design: description

A Claude Code skill that writes a one-page game vision (`design/one-page-design.md`) in seven sections: mantra and player fantasy, up to three pillars, narrative or mechanical summary, hook, interface, art style, music and sound. It pre-fills from the brief or concept doc, stress-tests each section, never invents references, and marks anything unfilled as OPEN. Layout adapted from the DevPods one-page template.
