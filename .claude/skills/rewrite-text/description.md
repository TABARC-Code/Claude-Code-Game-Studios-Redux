# rewrite-text: description

A Claude Code skill that rewrites supplied in-game text (dialogue, barks, lore, item text) to read as human, using the speaker's Voice Profile, the project style guide and a shared dialogue-craft reference. It keeps facts, keys and `{placeholders}`, checks lengths, placeholders and dashes with scripts, shows before and after, and writes only on approval. A missing voice profile or style setting is reported as not assessed.
